# L-MPV — Архитектура проекта и База Знаний

Данный документ содержит полную и актуальную информацию об устройстве медиаплеера **L-MPV**, его архитектуре, технологическом стеке, структуре файлов, взаимодействии Rust и React, детальном реестре IPC-команд и всех пользовательских функциях плеера.

---

## 1. Стек технологий и Портативность

- **Фронтенд:** React 19 + TypeScript + Vite + Lucide Icons + Vanilla CSS (Design Tokens, Glassmorphism, CSS Custom Properties).
- **Бэкенд:** Rust + Tauri v2.
- **Медиа-движок:** `libmpv-2.dll` (или `mpv-2.dll` / `mpv-1.dll`), задействован динамический FFI через `libloading`.
- **Портативный режим (Portable Architecture):**
  - Приложение полностью отвязано от диска и реестра Windows.
  - Все пути определяются динамически во время выполнения через `std::env::current_exe().parent()`.
  - Портативная структура папки `Portable-L-MPV/`:
    - `L-MPV.exe` — главный исполняемый файл.
    - `mpv-2.dll` — нативная библиотека воспроизведения mpv.
    - `config/` — локальные конфигурации (включает `settings.json`).
    - `screenshots/` — папка сохранения кадров по умолчанию.

## 3. Архитектура Бэкенда (Rust)

### 3.1. `mpv_manager.rs`
- Динамически загружает `mpv-2.dll` (или `libmpv-2.dll` / `mpv-1.dll`) через `libloading`.
- **Основной плеер:** Настраивает профиль высокого качества: `profile=gpu-hq`, `gpu-api=d3d11`, `hwdec=auto-safe`, `scale=ewa_lanczossharp`, `cscale=mitchell`.
- **HDR & Color Management:** `target-colorspace-hint=yes`, `tone-mapping=auto`, `hdr-compute-peak=yes`.
- **Оптимизация буферизации:** `background=#000000`, `demuxer-max-bytes=150MiB`, `demuxer-readahead-secs=5`, `demuxer-mkv-subtitle-preroll=yes`, `sub-auto=fuzzy`.
- **Отключение встроенного UI:** `osc=no`, `osd-level=0`, `input-default-bindings=no`, `input-vo-keyboard=no`.
- **Скриншоты:** Формат по умолчанию принудительно установлен в `png` (`screenshot-format=png`).

### 3.2. `lib.rs`
- Извлекает HWND окна Tauri v2 и передает его в mpv через свойство `"wid"`, связывая видеопоток с поверхностью окна Webview2.
- Регистрирует все **36 IPC-команд** в `tauri::Builder`.

## 4. Полный Реестр IPC-Команд Rust (`commands.rs`)

В бэкенде зарегистрировано **36 IPC-команд**:

| Категория | IPC Команда | Параметры | Возвращает | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **Воспроизведение** | `open_file` | `path: String` | `Result<(), String>` | Загрузка файла в основной плеер + авто-создание плейлиста из папки |
| | `toggle_pause` | — | `Result<(), String>` | Переключение паузы (`cycle pause`) |
| | `set_pause` | `paused: bool` | `Result<(), String>` | Явная установка паузы (`yes` / `no`) |
| | `seek` | `seconds: f64` | `Result<(), String>` | Относительная перемотка (`relative+exact`) |
| | `seek_absolute` | `seconds: f64` | `Result<(), String>` | Переход к указанной секунде (`absolute+exact`) |
| | `frame_step` | — | `Result<(), String>` | Шаг на 1 кадр вперед |
| | `frame_back_step` | — | `Result<(), String>` | Шаг на 1 кадр назад |
| | `playlist_prev` | — | `Result<(), String>` | Переход к предыдущему файлу в плейлисте |
| | `playlist_next` | — | `Result<(), String>` | Переход к следующему файлу в плейлисте |
| | `get_playlist` | — | `Result<Vec<PlaylistItem>, String>` | Чтение элементов внутреннего плейлиста MPV |
| | `play_playlist_item` | `index: i64` | `Result<(), String>` | Воспроизведение конкретного файла плейлиста по индексу |
| **Громкость / Скорость** | `set_volume` | `volume: f64` | `Result<(), String>` | Громкость от 0.0 до 100.0 |
| | `set_speed` | `speed: f64` | `Result<(), String>` | Установка множителя скорости (например, 1.25) |
| **Дорожки** | `get_tracks` | — | `Result<Vec<TrackInfo>, String>` | Список дорожек (аудио, субтитры, видео) с ID и языком |
| | `set_audio_track` | `track_id: i64` | `Result<(), String>` | Переключение аудиодорожки по ID (`aid`) |
| | `set_subtitle_track` | `track_id: i64` | `Result<(), String>` | Переключение субтитров по ID (`sid`) |
| | `disable_subtitles` | — | `Result<(), String>` | Отключение субтитров (`sid = "no"`) |
| | `load_subtitle_file` | `path: String` | `Result<(), String>` | Подключение внешнего файла субтитров (`sub-add`) |
| | `set_video_track` | `track_id: i64` | `Result<(), String>` | Переключение видеопотока по ID (`vid`) |
| **Вид, Зумирование и Настройки** | `set_aspect_ratio` | `ratio: String` | `Result<(), String>` | Установка соотношения сторон (`16:9`, `21:9`, `4:3`, `no`) |
| | `set_rotation` | `degrees: i64` | `Result<(), String>` | Поворот видеокадра (`0`, `90`, `180`, `270`) |
| | `set_video_zoom_and_pan` | `zoom: f64, pan_x: f64, pan_y: f64` | `Result<(), String>` | Аппаратный видеозум и панорамирование в mpv (`video-zoom`, `video-pan-x`, `video-pan-y`) |
| | `get_video_zoom` | — | `Result<f64, String>` | Получение текущего коэффициента зума |
| **Скриншоты** | `take_screenshot` | — | `Result<(), String>` | Сохранение текущего кадра без OSD (`screenshot video`) |
| | `get_screenshot_dir` | — | `Result<String, String>` | Чтение текущей директории для скриншотов |
| | `set_screenshot_dir` | `path: String` | `Result<(), String>` | Изменение пути скриншотов с записью в `settings.json` |
| **Главы** | `get_chapters` | — | `Result<Vec<ChapterInfo>, String>` | Получение списка всех глав текущего медиафайла |
| | `seek_chapter` | `index: i64` | `Result<(), String>` | Переход к главе по индексу (`chapter`) |
| **Метаданные и Поллинг** | `get_playback_state` | — | `Result<PlaybackState, String>` | Легкий динамический статус плеера (позиция, кадр, пауза, громкость, битрейт, пропуски) |
| | `get_media_info` | — | `Result<MediaInfo, String>` | Полный статический снапшот файла (кодеки, разрешение, FPS, HDR, битрейт, длительность) |
| | `get_position` | — | `Result<f64, String>` | Текущее время воспроизведения (в секундах) |
| | `get_duration` | — | `Result<f64, String>` | Полная длительность видео (в секундах) |
| | `get_frame_number` | — | `Result<i64, String>` | Номер текущего кадра (`estimated-frame-number`) |
| | `get_frame_count` | — | `Result<i64, String>` | Общее количество кадров (`estimated-frame-count`) |
| | `get_fps` | — | `Result<f64, String>` | Частота кадров (`container-fps`) |

## 5. Подробное Описание Всех Функций Плеера (User Capabilities)

### 5.1. Управление Воспроизведением и Навигация
- **Открытие медиафайлов и Авто-плейлист:**
  - Нажатие `Ctrl+O` или выбор пункта *"Открыть файл..."* в контекстном меню.
  - При открытии файла плеер автоматически сканирует родительскую директорию, находит все поддерживаемые видеофайлы, сортирует их по имени и фоново формирует порядок плейлиста (`loadfile append`).
  - Быстрый переход по плейлисту через кнопки Предыдущий/Следующий трек на панели управления или вызов IPC-команд `playlist_prev` / `playlist_next`.
  - Выдвижная боковая панель **Playlist Drawer** (горячие клавиши `L` / `P` или кнопка с иконкой списка на нижней панели): полная фильтрация по имени, отображение текущего файла и переход по клику.
  - Перетаскивание файлов на окно плеера (Drag & Drop) через нативное событие `onDragDropEvent` вебвью.
- **Пауза и Старт:**
  - Одиночный клик ЛКМ по рабочей области видео (с задержкой дебаунса 220мс для дифференциации с двойным кликом).
  - Нажатие клавиши `Space` (Пробел).
  - Нажатие центральной кнопки Play/Pause на плавающей панеле управления.
- **Покадровая перемотка (Precision Frame Stepping):**
  - Клавиши `←` / `,` / `Б` — шаг на 1 кадр назад.
  - Клавиши `→` / `.` / `Ю` — шаг на 1 кадр вперед.
  - Всплывающее OSD-уведомление в левом верхнем углу (`<текущий_кадр> / <всего_кадров>`).
- **Быстрая перемотка:**
  - Кнопки `-10 сек` и `+10 сек` на панели управления.
  - Клик по полосе таймлайна (абсолютный переход в любую точку видео).
- **Навигация по главам (Chapters Modal) и Подсказки:**
  - При наведении курсора на таймлайн во всплывающем превью показывается точное время и название текущей главы (нативный белый системный прямоугольник убран).

### 5.2. Визуальное Отображение, Зумирование и Рендеринг (Video, Zoom & Display)
- **Ограничение окна при старте:**
  - Окно при открытии файлов ограничивается до 1280x720 или 50% экрана без появления черных рамок.
- **Плавное аппаратное зумирование и панорамирование (Ctrl + Колесо мыши):**
  - Зажатие `Ctrl` + прокрутка колеса мыши позволяет центрировано масштабировать видеокадр относительно курсора мыши.
  - Оптимизировано с уменьшенным шагом (0.04) и батчингом через `requestAnimationFrame` (до 60 fps).
  - Магнитная привязка к 100% при приближении к исходному размеру (`zoom = 0`).
  - Горячая клавиша `Ctrl + 0` мгновенно сбрасывает масштаб и панорамирование к 100%.
- **Колесо мыши без Ctrl:**
  - Прокрутка колесика над видеообластью без Ctrl осуществляет точную плавную регулировку громкости плеера (шаг 5%) с сохранением значения в `localStorage`.
- **Изменение соотношения сторон (Aspect Ratio):**
  - Переключение режимов: *Оригинальное* (`no`), *16:9*, *21:9 (CinemaScope)*, *4:3*.
- **Поворот кадра (Video Rotation):**
  - Поворот на *0°*, *90°*, *180°*, *270°* по часовой стрелке.
- **Полноэкранный режим (Fullscreen):**
  - Двойной клик ЛКМ по рабочей области видео или кнопка разворачивания на панели управления.
- **Режим PiP (Picture-in-Picture / Поверх всех окон):**
  - Переключатель *"Поверх всех окон"* в ПКМ-меню и кнопка-булавка на панели управления.

### 5.3. Звук, Дорожки и Субтитры (Audio & Subtitles)
- **Регулировка Громкости:**
  - Слайдер от 0% до 100% на панели управления и прокрутка колеса мыши. Персистентное сохранение громкости в `localStorage` (`l-mpv-volume`).
- **Переключение Аудиодорожек и Субтитров:**
  - **ЛКМ по иконке:** мгновенное цикличное переключение на следующую дорожку.
  - **ПКМ по иконке:** открытие выпадающего списка со всеми дорожками (повторный клик закрывает меню).
  - Текстовые метки с названием или языком дорожек отображаются рядом с иконками (с возможностью отключения в настройках).
- **Скорость воспроизведения:**
  - Выбор множителей *0.25x*, *0.5x*, *0.75x*, *1.0x*, *1.25x*, *1.5x*, *2.0x*.

### 5.4. Скриншоты и Настройки (Screenshots & Settings)
- **Создание Скриншотов:**
  - Кнопка с иконкой фотоаппарата `<Camera />` на панели управления, горячая клавиша `S` / `Ы` или выбор в ПКМ-меню. Сохранение чистого кадра без OSD.
- **Настройка папки скриншотов, Акцентных Цветов и Кастомных Клавиш:**
  - В модальном окне `SettingsModal`:
    - Выбор папки скриншотов или сброс на портативную папку `screenshots`.
    - Выбор акцентных пастельных цветов (включая **#e8a236** Amber и **#FFA9DE** Pink).
    - Кастомная перепривязка любых горячих клавиш с кнопкой **«Сбросить»** до значений по умолчанию.

### 5.5. Архитектура Оптимизированного Поллинга и UX
- **Умная обработка IDLE (Бездействия):**
  - Плеер НЕ тушит интерфейс, если курсор находится над панелью управления, титлбаром или если открыто любое всплывающее окно/меню (плейлист, субтитры, настройки).
  - Сброс таймера происходит от движений мыши, кликов, скролла и нажатий клавиш.

## 6. Инструкция по Сборке и Релизу

Для компиляции и перегрузки готового исполняемого файла используются следующие команды:

1. **Компиляция проекта:**
   ```bash
   npm run tauri build
   ```
   *Результат сборки создается в папке:* `d:\My-programs\L-MPV\src-tauri\target\release\l-mpv.exe`

2. **Копирование в портативную папку:**
   ```powershell
   Copy-Item -Path "D:\My-programs\L-MPV\src-tauri\target\release\l-mpv.exe" -Destination "D:\My-programs\L-MPV\Portable-L-MPV\L-MPV.exe" -Force
   ```
   *(Если файл заблокирован запущенным плеером, сначала завершите процесс через `Stop-Process -Name "L-MPV" -Force`).*
