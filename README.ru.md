## 🌟 О проекте

<img src="https://github.com/Menely/L-MPV/blob/main/assets/L-MPV_icon_watercolor.png" width="30" height="30" align="absmiddle"> **[L-MPV](https://t.me/+_ngzHkrUNZs5YzQ6)** — это современный настольный медиаплеер для Windows, объединяющий возможности нативного видеодвижка **MPV** (`vo=gpu-next`, Direct3D 11, HDR, WASAPI, sinc-ресемплинг), аппаратный **Real-Time 4K AI Апскейлинг** (ONNX инференс через DirectML и TensorRT) и настраиваемый интерфейс в стиле **Glassmorphism**, созданный на **React 19** и **TypeScript**.

L-MPV хранит настройки, кэш, скриншоты, ONNX-модели и нативные библиотеки в папке приложения. Для работы нужен WebView2 Runtime; AI-компоненты загружаются отдельно. Ассоциации файлов и интеграция с Проводником включаются по желанию пользователя.

## ✨ Ключевые Возможности

<details>
<summary><b>🚀 Real-Time 4K AI Upscaling (Нейросетевой Апскейлинг Аниме и Видео)</b></summary>

<p align="center">
  <img src="./assets/ai-upscale.png" alt="Real-Time 4K AI Upscaling Before / After" width="100%" style="border-radius: 12px; box-shadow: 0 8px 30px rgba(0,0,0,0.5);">
</p>

- **Нативный инференс в видеопотоке:** интеграция фильтра `vf_animejanai` на базе актуального стека `mpv-AnimeJaNai 3.10.0` (мост `aji` v0.25.0, NVIDIA TensorRT 11.4.0.106 и DirectML DirectX 12) с аппаратным выводом кадров в 4K Ultra HD в реальном времени.
- **Два режима работы:** переключатель **«Выкл»** и **«AI Upscaling»** в Настройках (`F2`) — пользователь сам решает, когда задействовать искусственный интеллект.
- **Два движка инференса (Backend):**
  - **DirectML:** инференс через DirectX 12 на совместимых видеокартах AMD, Intel и NVIDIA. Поддержка моделей и скорость зависят от оборудования.
  - **TensorRT:** инференс на поддерживаемых видеокартах NVIDIA, включая архитектуры от `sm75` до Blackwell `sm120`.
- **Загрузка компонентов («Скачать движок»):**
  - Определение GPU и выбор соответствующих библиотек после нажатия «Скачать движок» или «Обновить движок».
  - Потоковая индикация процентов, объёма (МБ), аккуратный статус распаковки и фиксация 100% готовности в течение 3 секунд.
  - Неблокирующая фоновая распаковка через `spawn_blocking` без зависаний UI и без всплывающих консольных окон.
- **Предварительная компиляция TensorRT 1080p (.engine):**
  - Старые или неподтверждённые кэши помечаются для пересборки. Подтверждённые engines могут сохраняться после обновления libmpv/aji, если модель, GPU и ядро TensorRT остаются совместимыми. Валидные профили разных разрешений могут сосуществовать; готовность 1080p показывается отдельно. Действия «Обновить движок» и «Пересобрать» выполняются по нажатию пользователя, ONNX-модели сохраняются. Загруженные DLL требуют перезапуска перед заменой.
  - Ошибка загрузки или распаковки сохраняет установленный рантайм и его паспорт проверки. Новый комплект проверяется до замены установленных компонентов.
  - Фоновая оптимизация ONNX моделей под разрешение 1080p -> 4K с многоступенчатым отслеживанием фаз (разбор ONNX, тактики CUDA, оптимизация графа, сериализация).
  - Компиляция через `trtexec.exe` с профилем входного изображения 1080p.
  - Предварительная компиляция может сократить задержку запуска для соответствующей модели и профиля. Повторная сборка доступна в настройках.
- **Преобразование FP16 и совместимость моделей:**
  - Для преобразования FP32 в FP16 перед компиляцией нужен конвертер из пакета компонентов либо Python с модулями `onnx` и `onnxconverter-common`.
  - Совместимость, качество изображения и производительность зависят от модели и движка инференса.
- **Универсальная библиотека ONNX (`models/onnx/`):**
  - Поддерживаются совместимые с AnimeJaNai модели `.onnx`; произвольная архитектура ONNX не гарантирует совместимость.
  - Кнопка **«Папка моделей»** для быстрого перехода в Проводник Windows.
  - Переключатель скрытия/отображения названий моделей (маскировка точками).
  - Интерактивное перемещение порядка моделей мышкой (`@dnd-kit/sortable`) за ручку захвата с сохранением в `config/models_order.json`.
  - Сочетания клавиш и действия мыши для моделей меняются во вкладке «Горячие клавиши»; в карточках моделей кнопок назначения нет.
- **Переключение нейросетей на лету по горячим клавишам (до 9 моделей):**
  - `Ctrl+J` — Информационный OSD-оверлей статуса и статистики апскейлинга (активный движок, выбранная модель, слот, разрешение видео -> 4K);
  - **Избранная модель апскейлинга:** отметьте одну модель звёздочкой и включайте или выключайте её клавишей `U`. Выбор сохраняется вместе с переносимыми настройками и привязан к имени файла, поэтому сохраняется при перестановке моделей. Если избранная модель не выбрана или её файл отсутствует, плеер показывает сообщение.
  - `Shift+Backquote` — выключить апскейлинг (клавиша под Esc, Ё в русской раскладке);
  - `Shift+1` .. `Shift+9` — Включить Нейросеть #1 .. #9 (горячие клавиши доступны для первых 9 моделей);
  - OSD-уведомление с отображением реального названия активированной модели;
  - Принудительная перерисовка кадра на паузе при смене модели.
  - При обновлении прежние стандартные сочетания заменяются новыми; пользовательские назначения и отключённые действия сохраняются.

</details>

<details>
<summary><b>🌍 Мультиязычный Интерфейс (Русский / English)</b></summary>

- **Два языка из коробки:** интерфейс переведён на русский и английский языки.
- **Переключение языка:** смена языка в настройках не требует перезапуска плеера, интерфейс переводится на лету.
- **Автоопределение языка:** плеер автоматически подхватывает системный язык вашей Windows при первом запуске (русский для русскоязычных систем, английский по умолчанию для всех остальных).
- **Двуязычный установщик Windows:** мастер установки NSIS поддерживает выбор языка (Русский / English) с автоматическим определением локали системы и полной локализацией диалогов.

</details>

<details>
<summary><b>⚡ Рендеринг видео (<code>vo=gpu-next</code>) и Автоподгонка Окна</b></summary>

- **Высококачественный пайплайн:** рендерер `vo=gpu-next`, нативный Direct3D 11 (`gpu-api=d3d11`), аппаратное декодирование `hwdec=auto-safe` и перцептуальный gamut mapping (`gamut-mapping-mode=perceptual`).
- **Масштабирование изображения:** алгоритмы интерполяции `scale=spline36` и `cscale=spline36` для сохранения чёткости деталей и плавности цветовых переходов.
- **HDR и тонемаппинг:** автоматический тонемаппинг и передача подсказок о цветовом пространстве дисплея; параметры обработки HDR доступны в настройках.
- **Дизеринг и уменьшение бандинга:** адаптивный пространственно-временной дизеринг с синим шумом (`dither-depth=auto`), согласованный с матрицей дисплея, и опциональный GPU-шейдер дебандинга (`deband`) со сбалансированными пресетами силы для устранения ступенчатых градиентов в аниме и пережатых веб-рипах.
- **Автоподгонка окна:** размер окна учитывает пропорции видео и масштаб монитора. В режиме вписывания, полном экране и при ограничениях размера могут оставаться чёрные полосы.
- **Автоматический сброс масштаба и смещения:** при открытии нового медиафайла сбрасываются параметры масштаба и положения кадра.
- **Запуск с файлом:** плеер подготавливает файл на паузе, подгоняет и показывает окно, затем начинает воспроизведение. Явно заданная пауза сохраняется. Время запуска зависит от файла и системы.
- **Нативный вывод видео:** mpv выводит видео в Windows HWND под прозрачным интерфейсом WebView2.
- **Распознавание файлов YUV:** `.yuv` включены в выбор файлов, плейлист из папки и необязательные ассоциации Windows. Параметры raw-видео автоматически не задаются.

</details>

<details>
<summary><b>🎵 Нативный Аудио-Визуалайзер (WASAPI Loopback Capture / FFT 1024)</b></summary>

- **Спектральный анализ:** нативный захват системного звука через Windows WASAPI Loopback Capture в фоновом Rust-потоке с вычислением 1024-точечного БПФ (Cooley-Tukey Radix-2 FFT) со сглаживающим окном Ханна.
- **32 частотные полосы:** детальное частотное разрешение 46.8 Гц на бин. Логарифмическое распределение от 25 Гц до 19 000 Гц со строгой монотонностью полос (суб-бас, панч, вокал, презенс, высокие частоты).
- **Сведение 5.1 / 7.1 Surround:** при подготовке звука для визуализатора учитываются центральный канал и канал LFE.
- **Логарифмическая шкала:** диапазон отображения от -46 до 0 dB с частотной компенсацией. Дополнительная компенсация визуального усиления зависит от громкости плеера.
- **9 стилей визуализации:** такие как `Waveform` (многослойная волна с динамическими спектральными гармониками), `Spectrum` (32-полосный эквалайзер) и `Bars` (ритм-капсулы Apple Music / Spotify style) и так далее.
- **Индикаторы пиков:** удержание и постепенное снижение маркеров показывают изменения уровня сигнала.
- **Снижение фоновой активности:** на паузе и при неактивном интерфейсе захват звука останавливается. Поток периодически проверяет, нужно ли возобновить работу.

</details>

<details>
<summary><b>🌌 Аппаратная Подсветка Полос (Ambient Light / GPU Blur)</b></summary>

- **Размытие полос:** при несовпадении пропорций видео и окна свободные области вокруг кадра заполняются размытым на GPU фоном.
- **2 режима работы:**
  - `Off` — классические черные полосы;
  - `Blur` — аппаратное шейдерное размытие кадра в реальном времени с плавной регулировкой радиуса (от 5 до 150 px); устаревший тяжелый режим `Color` удален в v2.7.0 для упрощения доступных режимов.
- **Предпросмотр:** изменения применяются сразу, сохранение настроек выполняется с задержкой 400 мс. Частота кадров зависит от оборудования и видео.
- **Быстрое управление:** переключение по горячей клавише `B` (`Off → Blur → Off`), в контекстном меню (ПКМ) и в Настройках.

</details>

<details>
<summary><b>🎧 Вывод звука и усиление громкости</b></summary>

- Вывод через Windows WASAPI с настроенным аудиобуфером 0,2 секунды.
- Громкость до 150% и опциональный пиковый лимитер. Ограничение пиков и изменение усиления могут менять сигнал; побитовая точность вывода не гарантируется.
- Настройки задержки аудиоустройства для уменьшения потери начала звука на некоторых устройствах.
- Настроенный sinc-ресемплинг, нормализованное сведение многоканального звука и коррекция тона при изменении скорости.

- **Индикатор громкости:** необязательная шкала ниже центра экрана или текстовый OSD слева сверху. По умолчанию выключен; включается в «Настройки видео и звука» → «Аудиотракт», вид переключается чекбоксом OSD.

</details>

<details>
<summary><b>🎧 Управление Дорожками и Экспорт в 1 Клик (Track Popover & FFmpeg)</b></summary>

- **Адаптивный дизайн под выбранный стиль плеера:**
  - В стиле **«Капсула»** меню представлено парящими карточками: отдельная шапка со счётчиком дорожек и кнопкой быстрого перехода к поиску субтитров (`Ctrl+F`), независимая карточка для быстрого отключения субтитров и аккуратный список дорожек;

- **Direct Stream Copy (`-c copy`):** извлечение без перекодирования и без малейшей потери исходного качества за считанные секунды.

- **Отрисовка субтитров и экранных надписей:** поддержка стилизованных ASS/SSA-субтитров, караоке-анимаций и экранных надписей:

- **Табличные цифры:** одинаковая ширина цифр помогает сохранять выравнивание времени, битрейта и счётчиков при обновлении значений.
- **Единая кинетическая система анимаций:** 5 стандартизированных уровней длительностей (`--t-instant`, `--t-fast`, `--t-base`, `--t-pop`, `--t-drawer`) и 4 кривые Безье (`--ease-smooth`, `--ease-decelerate`, `--ease-accelerate`, `--ease-spring-smooth`), согласованные между CSS и TypeScript.

<summary><b>✨ Интерактивный Таймлайн: Neon Pulse Wave и Live Scrubbing</b></summary>

- **Адаптивное увеличение по главам (Segmented Chapter Hover):** при наведении курсора на видео с главами плавно увеличивается по высоте (с 5px до 8px) только та часть шкалы, которая принадлежит активной главе под курсором, в то время как остальные сегменты сохраняют стандартную аккуратную толщину (5px). Для видео без глав сохранено классическое равномерное увеличение всей шкалы целиком.
- **Кинематическая волна Neon Pulse Wave:** компактное кольцо неонового свечения (36px), расходящееся от точки клика по полосе таймлайна с адаптацией под активный акцентный цвет плеера. При отключенных анимациях волна не создаётся вовсе, поэтому кольцо не может «залипнуть» поверх кнопок панели управления.
- **Перемотка перетаскиванием:** движение указателя обновляет позицию предпросмотра на таймлайне.
- **Кадр при наведении:** для локального видео над таймлайном показывается миниатюра с временем и главой. В «Общие → Воспроизведение» доступен сохраняемый переключатель предосмотра. Для 4К во время движения используются готовые миниатюры и ключевые кадры, после остановки — точный кадр. Работает независимый внутрипроцессный декодер libmpv с ограниченным кешем в памяти и на диске. При выключении предосмотра подсказки времени и главы остаются доступны.
- **Предпросмотр и точная перемотка:** при перетаскивании используются переходы к ключевым кадрам, при отпускании выполняется точный переход к выбранной позиции.
- **Расчёт позиции при отпускании:** позиция финального перехода считается по свеже измеренному прямоугольнику шкалы (кэш сбрасывается при ресайзе окна), поэтому автоподгонка окна под пропорции видео больше не сбивает позицию.
- **Никаких лишних рамок фокуса:** клик мышью по таймлайну больше не оставляет зелёную рамку `:focus-visible` поверх видео; индикатор клавиатурного фокуса сохранён через рост полосы прогресса с 5px до 8px.
- **Настраиваемый шаг перемотки и синхронизация:** кнопки панели управления и клавиши-стрелки `←` / `→` работают на единый шаг перемотки (по умолчанию 10 секунд; шаг 1–300 сек задаётся в Настройках).
- **Индикатор перемотки:** показывает направление и выбранное число секунд знаковым значением и направленной шкалой. Быстрые повторы в одном направлении суммируются на экране.
- **Стабильная эргономика управления:** клик по таймлайну больше не перехватывает фокус клавиши `Space` (воспроизведение продолжается по первому нажатию), а навигация стрелками не вызывает ложного появления скрытого интерфейса.
- **Время по центру:** счётчик соответствует выбранному стилю плеера и сохраняет полный формат времени, не увеличивая высоту панели управления.

<summary><b>📊 Тепловая карта таймлайна</b></summary>

- Уровни RMS и пиков звука в dBFS либо видеобитрейт с секундной детализацией.
- Звук декодируется FFmpeg и анализируется в Rust. Видеопакеты анализируются без декодирования кадров: поддерживаемые Matroska/WebM обрабатываются Rust-библиотекой, для остальных случаев используется FFmpeg.
- Шесть видов графика: столбики, сплайн, блоки, залитый рельеф, ступенчатый контур и точечный рельеф. Восемь палитр: акцент темы, термальная, киберпанк, монохром, Sunset, Aurora, Ocean и Plasma.
- Настройка высоты, прозрачности и расположения над таймлайном или панелью управления. По умолчанию карта выключена; включается в настройках.
- При наведении показываются RMS/Peak либо средний битрейт выбранного интервала. Видеобитрейт отображается по сбалансированной шкале; число видимых столбиков адаптируется к ширине окна.
- Аудио- и видеопрофили сохраняются раздельно в `data/cache/waveforms/audio/` и `data/cache/waveforms/video_bitrate/`. Ключи BLAKE3 учитывают метаданные файлов и выбор дорожки. При смене источника устаревший анализ отменяется.
- В разделе «Система → Кеш» доступны размеры дисковых кешей и очистка. Старые папки кеша автоматически переносятся в data/cache; настройки, история и модели сохраняются.

- В настройках есть предпросмотр и очистка кэша.

<summary><b>🖥️ Полноэкранный режим и управление окном</b></summary>

- **Полноэкранный режим:** используются нативные средства управления окном Windows.
- **Динамический Z-порядок (`handle_window_focus`):** при переключении на другое приложение (`Alt+Tab`) плеер автоматически снимает статус Topmost, позволяя окнам свободно открываться поверх плеера, и восстанавливает его при возврате фокуса.

- **Масштаб видеокадра и поворот:** три режима вписывания кадра в окно — *Растянуть до размера окна* (заполняет окно без сохранения пропорций), *Вписать в окно* (весь кадр виден, чёрные полосы), *Заполнить экран и обрезать кадр* (заполняет окно, края обрезаются), — и поворот на 0°, 90°, 180°, 270°. Активный режим считывается из mpv и отмечается в контекстном меню.
- **Фиксация пропорций:** при растягивании окна за края и углы сохраняется выбранное соотношение сторон. Оно учитывает видеокадр; без видео используется 16:9.

<summary><b>📑 Плейлист и навигация</b></summary>

- **Запуск и буферизация:** показ начинается без ожидания заполнения всего буфера. Дальнейшая предзагрузка помогает переживать краткие просадки чтения; если данные закончились, плеер ожидает пополнения и продолжает воспроизведение. Фоновое сканирование и полный анализ тепловой карты откладываются при открытии файла и уступают чтению видео при перемотке или нехватке буфера. Скорость зависит от файла и носителя.
- **Автоматический плейлист с Natural Sort:** при открытии файла плеер находит все видео в директории и выстраивает плейлист в естественном порядке нумерации файлов.
- **Выдвижная панель плейлиста (`L` / `P`):** поиск файлов, фильтрация, подсветка активного трека и переключение в один клик.
- **Адаптация под выбранный стиль:**
  - В стиле **«Капсула»** окно плейлиста разделено на аккуратные парящие островки: заголовок со счётчиком файлов, кнопки управления, бесшовная строка поиска и независимый блок списка файлов;
  - В стилях **«Модерн»** и **«Классический»** плейлист оформлен в виде монолитной панели из матового полупрозрачного стекла.
- **Прокрутка списка:** поиск и индикаторы воспроизведения находятся в прокручиваемом списке файлов.
- **Элегантная индикация текущего видео:** аккуратный круглый бейдж с мягкой неоновой подсветкой номера текущего файла вместо грубых рамок на всю строку, сохраняя чёткость текста названия.
- **Drag & Drop:** при перетаскивании видео, аудио или субтитров над плеером рядом с курсором отображаются имя первого файла и иконка его типа; для видео используется значок L-MPV. У длинных имён сохраняется расширение, для нескольких файлов показывается количество дополнительных. При отпускании первый файл открывается или подключается по текущей настройке хотлоада.
- **Режимы повтора и Shuffle:** циклическое воспроизведение текущего файла, всего плейлиста или случайный порядок. Кнопка на панели и подменю «Режим повтора» в ПКМ-меню используют одну команду `set_repeat_mode`, которая всегда выставляет оба свойства повтора вместе; подменю сразу отмечает активный режим, смена подтверждается OSD.
- **Индикатор прогресса серий (Watch Progress Bar в стиле Netflix/YouTube):** изящная акцентная полоска снизу каждой карточки серии в плейлисте, отображающая процент просмотра из локальной истории (`get_watch_history_batch`). Полностью просмотренные эпизоды (досмотренные до конца) получают флаг `completed`, помечаются аккуратной зелёной галочкой `CheckCircle2` и заполненной линией со специальным стилем, а также поддерживается живое отслеживание прогресса текущего файла.
- **Защита от сплющивания в компактных окнах:** элементам плейлиста задана минимальная высота (`flex-shrink: 0`, `min-height: 38px`), обеспечивающая плавную вертикальную прокрутку со скроллбаром без взаимного наезда и расплющивания строк даже в самых маленьких окнах плеера.
- **Главы (Chapters):** модальное окно навигации по встроенным главам файла с интерактивными таймкодами.
- **Продолжение просмотра:** сохранение последней позиции для 300 файлов в `config/history.json` и восстановление при повторном открытии.
- **Интеграция с Windows Taskbar:** отображение индикатора прогресса воспроизведения прямо на иконке плеера в панели задач Windows.

<summary><b>💻 Системные Компоненты, Диагностика и Интеграция с Windows</b></summary>

- **Системная сводка:** характеристики плеера, кеш и интеграции Windows используют общий аккордеон. В таблице кеша показаны пути к папкам, размеры и количество файлов; доступна очистка отдельных категорий или всего кеша. Нажатие на путь копирует его. В стиле плеера «Капсула» диаграмма состоит из отдельных округлых сегментов, в остальных стилях отображается цельным кольцом. Диагностика предзагружается, обновляется по кнопке и копируется в отчёт.
- **Мониторинг нейросетевого инференса (AnimeJaNai / aji):** отображение исключительно установленных пользователем движков (`TensorRT 11`, `DirectML`, `aji v0.25.0`), а также количества моделей ONNX и скомпилированных движков `.engine`.
- **Аппаратное ускорение (GPU):** определение графического адаптера, объёма выделенной видеопамяти VRAM и аппаратной микроархитектуры CUDA (`sm120`, `sm89`, `sm86` и др.).
- **Ассоциации файлов (Windows):** однокликовое связывание медиафайлов с L-MPV в реестре Windows, безопасная отвязка и быстрый переход в системные параметры приложений по умолчанию.
- **Контекстное меню Проводника (MediaInfo):** интеграция пункта «L-MPV MediaInfo» в системное меню правой кнопки мыши Windows для мгновенного анализа медиафайлов.
- **Экспорт отчёта для техподдержки:** кнопка «Скопировать отчёт» формирует стандартизированный отчёт со всеми путями, библиотеками и характеристиками оборудования для GitHub Issues.
- **Сворачиваемая интеграция Windows:** ассоциации файлов и контекстное меню Проводника находятся в отдельных раскрывающихся разделах. Статус меню обновляется при открытии и по кнопке «Обновить», учитывая внешние изменения.
- **Журнал операций:** появляется при наличии результатов или ошибок и сворачивается отдельно.

<details>
<summary><b>📊 Анализ Свойств Медиаконтейнера (MediaInfo.dll C-API)</b></summary>

- **Нативный анализ без внешних консолей:** прямое C-FFI связывание с `mediainfo.dll` через `libloading` для сбора исчерпывающей информации обо всех видео, аудио и субтитрах.
- **Полноценное независимое окно ОС Windows (655×685 px):** окно MediaInfo можно свободно перемещать за пределы плеера на любой монитор; открывается поверх плеера (`Shift+F10`) с возможностью открепления кнопкой-булавкой (Pin / `alwaysOnTop`).
- **Кэш последних отчётов:** при повторном открытии того же неизменённого файла готовый отчёт остаётся на экране. Анализ повторяется, если файл изменён или отчёта больше нет в кэше текущего процесса.
- **Автономный просмотр («Открыть в L-MPV MediaInfo»):** техническая информация о файле из контекстного меню Проводника, без показа главного окна и запуска воспроизведения.
- **Гармоничная адаптация под стиль и цвет плеера:** окно MediaInfo подстраивается под выбранный стиль оформления («Капсула», «Модерн», «Классический») и автоматически перенимает цветовую тему плеера даже при открытии отдельного файла из Проводника Windows. В стиле «Капсула» элементы аккуратно разбиты на парящие карточки с выверенной геометрией.
- **Интерактивные чипы-вкладки категорий потоков (Quick Filter):** фильтрация дорожек по секциям (*«Все»*, *«Общее»*, *«Видео»*, *«Аудио»*, *«Субтитры»*, *«Главы»*) с информативными бейджами количества потоков и скруглением 6px в едином стиле интерфейса.
- **Сворачиваемые секции (Accordion):** индивидуальное и массовое («Свернуть/Развернуть все») сворачивание секций контейнера с умным автораскрытием секций при поиске по `Ctrl+F`.
- **Нативный Drag-and-Drop:** перетаскивание любых медиафайлов прямо в открытое окно MediaInfo с полупрозрачным оверлеем (`FileUp`) и обновлением анализа.
- **Компактный оверлей (`I`):** три вкладки — «Сводка», «Рендеринг» и «Дорожки»; переключение кликом или клавишами `1` / `2` / `3`. «Рендеринг» показывает CPU и RAM процесса/системы, сведения о GPU и VRAM, декодере, цвете, частоте дисплея и A/V-синхронизации. Доступность показателей зависит от системы и файла; процент загрузки GPU не измеряется. Показан адаптер с наибольшим объёмом выделенной видеопамяти, который может отличаться от используемого для воспроизведения; занятость VRAM относится к процессу L-MPV, а не ко всей системе. Во вкладке «Дорожки» можно выбрать аудио и субтитры, отключить активную дорожку повторным кликом и перейти к главе. График видеобитрейта в «Сводке» сглажен, может использовать метаданные и декоративные колебания; это не прямое измерение размеров пакетов.
- **Интерактивный функционал:** поиск по свойствам (Ctrl+F) с подсветкой, экспорт в .txt, копирование в буфер обмена и переключение языков (RU/EN). Кнопки действий переведены в минималистичный режим чистых векторных иконок.

- **Автоматическая синхронизация на лету:** список пресетов обновляется при возврате фокуса в окно плеера (например, после ручного изменения или добавления `.json` файлов) или по кнопке «Обновить».

<details>
<summary><b>🖱️ Настраиваемое Контекстное Меню (ПКМ) и Drag-and-Drop Конфигуратор</b></summary>

- **Гармоничный дизайн под стиль плеера:**
  - В стиле **«Капсула»** главное меню оформлено в виде парящих карточек-островков, повторяющих эстетику нижней панели и плейлиста;
  - В стилях **«Модерн»** и **«Классический»** главное меню и подменю имеют цельный классический вид из матового стекла.
- **Минималистичные круглые индикаторы выбора:** активные режимы и выбранные дорожки отмечаются аккуратными светящимися точками-маркерами без избыточных рамок и галочек.
- **Текст меню:** оформление учитывает выбранный шрифт и стиль интерфейса.
- **Плавная прокрутка без видимого скроллбара:** в длинных списках подменю полоса прокрутки скрыта, при этом колесо мыши скроллит списки с помощью колеса мыши; зазор между главным меню и подменю зафиксирован на удобных 10px (`SUBMENU_GAP`), а клики по переключателям не захлопывают меню.
- **Подписи элементов управления:** у кнопок есть подписи для средств доступности; часть элементов также показывает браузерные подсказки.
- **Интерактивный Drag-and-Drop редактор:** визуальный конфигуратор в Настройках (`F2` -> «Основные» -> «Контекстное меню (ПКМ)») на базе движка `@dnd-kit` с поддержкой перетаскивания как за ручку-хват (Grip), так и за всю карточку пункта.
- **Действия контекстного меню:** выбор дорожек, главы, скорость, вписывание кадра, поворот, размытие полос, MediaInfo и пресеты оформления.
- **Динамические подменю:**
  - *«Пресеты настроек»*: выбор сохраненных пресетов пользователя и готовых стилей с отметкой активного выбора.
  - *«AI-Апскейлинг»*: включение/выключение и выбор модели нейросети из папки `models/onnx/`.
  - *«Кнопки панели управления»*: настройка видимости кнопок, включая перемотку, скорость и пропуск опенинга.
- **Синхронизация прозрачности с интерфейсом:** фон контекстного меню и выпадающих подменю привязан к общесистемной переменной `--bg-glass` и настройке `--ui-opacity`, плавно изменяя прозрачность синхронно с общим ползунком прозрачности плеера.
- **Закрытие по повторному ПКМ (Toggle):** повторный клик правой кнопкой мыши при открытом меню чисто закрывает его без паразитного переоткрытия и скачков координат.
- **Вставка разделителей (`divider`):** добавление горизонтальных черт в любое место меню для аккуратной группировки.
- **Портативное хранение (`config/context_menu.json`):** все изменения раскладки сохраняются локально в папке плеера. Кнопка «Сброс» позволяет в один клик вернуть исходную раскладку.

</details>

<details>
<summary><b>🛡️ Хранение настроек и фоновые задачи</b></summary>

- Настраиваемый приоритет процесса и мультимедийный профиль планировщика Windows для видеорендеринга. Эти настройки не гарантируют отсутствие пропущенных кадров.
- Настройки, история, пресеты, раскладка контекстного меню и кэш субтитров записываются через временный файл с атомарной заменой, что снижает риск неполной записи.
- Настройки и история используют блокировки, освобождаемые ОС после падения процесса. История сохраняет последнее обновление при досмотре, перемотке назад или повторном просмотре в одну секунду.
- При записи настроек и раскладки меню создаются резервные копии: до 10 версий каждого файла. Резервирование включено не для всех типов файлов.
- Фоновые задачи FFmpeg поддерживают владение процессами и отмену. Для внешних утилит заданы таймауты: запрос GPU — 4 секунды, распаковка — 120 секунд, сборка TensorRT — 15 минут.
- Одновременно компилируется только одна TensorRT-модель.

</details>

<details>
<summary><b>🔄 Система Целостности Обновлений и Откат Версий (BLAKE3 & Checksums)</b></summary>

- **Криптографическая верификация целостности (BLAKE3):**
  - При каждом обновлении или откате плеер проверяет хэши скачиваемых исполняемых файлов и библиотек (`l-mpv.exe`, `libmpv-2.dll`, `mediainfo.dll`) на лету, отсекая повреждённые файлы и обрывы сети.
- **Манифест `checksums.json` на диске пользователя:**
  - Скачанный и проверенный манифест сохраняется в корень папки плеера при обновлении. Манифест содержит ожидаемые BLAKE3-хэши файлов плеера.
  - Манифест также автоматически упаковывается внутрь архивов `L-MPV-v*-portable.zip`.
- **Подготовка установки и откат:** загрузки используют отдельные временные каталоги, применение обновлений сериализуется между экземплярами плеера. Если замена не удалась, обновление пытается восстановить старые файлы и удалить добавленные компоненты; при необходимости сохраняет файлы восстановления.
- **Встроенные контрольные суммы для отката (v2.0.0 – v2.5.6):**
  - Для поддерживаемых архивных версий в `updater.rs` сохранены контрольные суммы. Они используются для проверки файлов при откате.
- **Синхронизация при переименовании:**
  - Если пользователь переименовал исполняемый файл (например, в `L-MPV.exe` или `плеер.exe`), установщик обновлений автоматически подгоняет имя файла и перезаписывает именно рабочий бинарник.

</details>

<details>
<summary><b>🎛️ Нормализация и ночной режим звука</b></summary>

- **Динамическая нормализация:** фильтр `dynaudnorm` уменьшает перепады громкости между тихими и громкими участками.
- **Ночной режим:** RMS-компрессор `acompressor` приглушает громкие пики. Его влияние на диалоги зависит от уровня записи; речь отдельно не распознаётся.
- Нормализация и пиковый лимитер включаются независимо.
- При отключении обоих режимов очищается управляемая плеером цепочка `af`. На результат могут продолжать влиять ресемплинг, настройки устройства и другие этапы обработки звука.

</details>

## 🚀 Сборка и запуск

Инструкция рассчитана на **Windows 10/11 x64** и PowerShell. Все команды после клонирования выполняются из корня репозитория. Для обычного использования скачайте готовый плеер на [странице релизов](https://github.com/Menely/L-MPV/releases).

### Требования

- **Git** для клонирования репозитория.
- **Node.js 22.12+** с npm. Также поддерживается ветка Node.js 20 начиная с 20.19.
- **Rust** через [rustup](https://rustup.rs/), стабильный toolchain `stable-x86_64-pc-windows-msvc`.
- **Microsoft C++ Build Tools** с рабочей нагрузкой «Разработка классических приложений на C++», средствами MSVC x64 и Windows SDK.
- **Microsoft Edge WebView2 Runtime** для отображения интерфейса.

Ссылки на установку системных компонентов: [требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/#windows). После установки инструментов откройте PowerShell заново.

### 1. Клонирование и зависимости

```powershell
git clone https://github.com/Menely/L-MPV.git
Set-Location L-MPV
rustup toolchain install stable-x86_64-pc-windows-msvc
rustup override set stable-x86_64-pc-windows-msvc
npm ci
```

### 2. Нативные библиотеки

Файлы `libmpv-2.dll`, `ffmpeg.exe` и `mediainfo.dll` не хранятся в Git. Загрузите пакет из релиза `deps-v1`, который использует и автоматическая сборка проекта:

```powershell
New-Item -ItemType Directory -Force -Path src-tauri/binaries | Out-Null
Invoke-WebRequest -Uri "https://github.com/Menely/L-MPV/releases/download/deps-v1/mpv_libs.zip" -OutFile "mpv_libs.zip"
Expand-Archive -LiteralPath "mpv_libs.zip" -DestinationPath "src-tauri/binaries" -Force
Remove-Item -LiteralPath "mpv_libs.zip"

foreach ($name in @("libmpv-2.dll", "ffmpeg.exe", "mediainfo.dll")) {
    $nativeFile = Join-Path "src-tauri/binaries" $name
    if (!(Test-Path -LiteralPath $nativeFile) -or (Get-Item -LiteralPath $nativeFile).Length -eq 0) {
        throw "Missing or empty file: $nativeFile"
    }
}
```

При недоступности загрузки откройте [релиз deps-v1](https://github.com/Menely/L-MPV/releases/tag/deps-v1), скачайте `mpv_libs.zip` вручную и распакуйте три файла непосредственно в `src-tauri/binaries/`.

### 3. Запуск в режиме разработки

Разместите библиотеки рядом с отладочным исполняемым файлом, чтобы они находились независимо от рабочего каталога:

```powershell
New-Item -ItemType Directory -Force -Path src-tauri/target/debug | Out-Null
Copy-Item -Path "src-tauri/binaries/*" -Destination "src-tauri/target/debug/" -Force
npm run tauri -- dev
```

Команда запускает Vite и нативное окно Tauri. Первый запуск включает компиляцию Rust и загрузку зависимостей и может занять несколько минут. `npm run dev` отдельно запускает только веб-интерфейс: воспроизведение через Rust/libmpv в обычном браузере недоступно.

Для обычного воспроизведения AI-компоненты не нужны. Для апскейлинга загрузите движок в настройках плеера и добавьте совместимую ONNX-модель в папку `models/onnx/` рядом с запущенным `l-mpv.exe`. Производительность зависит от видеокарты и модели.

### Сборка и запуск release-версии

```powershell
npm run build:exe
if ($LASTEXITCODE -ne 0) { throw "Build failed" }
Copy-Item -Path "src-tauri/binaries/*" -Destination "src-tauri/target/release/" -Force
& "./src-tauri/target/release/l-mpv.exe"
```

Исполняемый файл находится в `src-tauri/target/release/l-mpv.exe`. Нативные библиотеки должны оставаться рядом с ним; настройки и рабочие данные создаются там же. Для переноса скопируйте исполняемый файл и содержимое `src-tauri/binaries/` в отдельную папку с правом записи.

Для создания NSIS-установщика:

```powershell
npm run build:bundle
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`. При первой сборке Tauri может загружать инструменты упаковки из сети.

### Проверки перед релизом

```powershell
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --locked
```

Vite может предупреждать о размере основного JavaScript-файла свыше 500 kB. Само по себе это предупреждение не означает ошибку сборки.
