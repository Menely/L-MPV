L-MPV UI Fonts / Шрифты интерфейса L-MPV
=========================================

В этой папке находятся вариативные шрифты (Variable Fonts),
используемые в интерфейсе медиаплеера L-MPV:

1. Inter-Variable.ttf           — Шрифт по умолчанию (эталон читаемости, кириллица + латиница)
2. Outfit-Variable.ttf          — Геометрический футуристичный стиль (латиница)
3. PlusJakartaSans-Variable.ttf — Утончённый нео-гротеск (латиница)
4. Manrope-Variable.ttf         — Современный полугеометрический гротеск (кириллица + латиница)
5. JetBrainsMono-Variable.ttf   — Профессиональный моноширинный шрифт для точных таймкодов и данных

Пользовательские шрифты:
------------------------
Вы можете скопировать в эту папку любые собственные файлы шрифтов
(.ttf, .otf, .woff, .woff2). Плеер L-MPV автоматически обнаружит их,
и они станут доступны для выбора в меню «Настройки -> Кастом -> Шрифты».

Как установить в Windows (опционально):
--------------------------------------
Кликните правой кнопкой мыши по любому файлу шрифта (.ttf / .otf)
и выберите «Установить» (или «Установить для всех пользователей»).
Плеер использует эти шрифты автоматически прямо из этой папки без
обязательной установки в операционную систему.
